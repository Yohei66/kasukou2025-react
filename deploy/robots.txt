# 試験用サーバー。誰でも見られるが、検索結果には載せない。
#
# ★ ここに Disallow を書かないでください。
#   検索から外す仕事は .htaccess の「X-Robots-Tag: noindex」が担当しています。
#   クロールを禁止すると検索エンジンがページを取得できなくなり、
#   その noindex を読み取れません。結果、外部リンクなどから URL だけを
#   拾って「説明のない検索結果」として載ってしまうことがあります。
#
#   ・巡回は許可する（Allow）
#   ・載せるかどうかは noindex で断る
#   この組み合わせが、認証なしで確実に検索から外す唯一の方法です。
#
# ★ 本番サーバーにはこのファイルも .htaccess も置かないこと。

User-agent: *
Allow: /
